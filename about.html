NEXA / CASE STUDY

Sobre o projeto.

Digital Learning Hub é um protótipo educacional fictício criado para demonstrar competências de front-end, arquitetura de informação e construção de experiências digitais sem dependência de CMS.

Web estática

Estrutura leve em HTML, CSS e JavaScript, fácil de executar, versionar e publicar.

Design responsivo

Layout adaptável para diferentes tamanhos de tela e contextos de uso.

Sistema visual

Tipografia, grid, contraste, componentes e motion derivados da linguagem visual NEXA Studio.

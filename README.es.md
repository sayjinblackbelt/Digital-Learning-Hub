## Sobre

**Digital Learning Hub** es un proyecto independiente reconstruido a partir de un prototipo institucional anterior y reposicionado como un **caso de portafolio autónomo**.

La versión actual utiliza el lenguaje visual de **NEXA Studio** para layout, tipografía, grid, contraste, componentes, motion y dirección gráfica. Todo el contenido mostrado es ficticio y sanitizado.

## 🎨 Dirección visual — NEXA Studio

- **Space Grotesk** para títulos e identidad;
- **DM Sans** para textos e interfaz;
- paleta oscura técnica con acentos luminosos;
- grid de 80px;
- bordes discretos y sombras mínimas;
- tipografía expresiva;
- motion sutil;
- componentes modulares y responsivos.

## 🧩 Case studies

La sección **Work** presenta proyectos ficticios dentro del mismo sistema visual: **Learning OS**, **Creator Lab** y **Signal / AI**, además de conceptos exploratorios.

El objetivo es demostrar la cadena **problema → sistema → interfaz → producto**, combinando diseño, desarrollo front-end y comunicación visual.

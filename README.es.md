# 💻 Digital Learning Hub

[🇧🇷 Português](README.md) | [🇺🇸 English](README.en.md) | 🇪🇸 Español

> Prototipo institucional educativo ficticio creado para estudiar front-end, diseño responsivo, accesibilidad y organización de contenido.

## Sobre

**Digital Learning Hub** es un proyecto independiente reconstruido a partir de un prototipo institucional anterior y reposicionado como un **caso de portafolio autónomo**.

La nueva versión elimina referencias a organizaciones, servicios, canales de comunicación, públicos, cifras operativas y otros elementos vinculados a contextos reales. Todo el contenido del sitio es demostrativo.

El objetivo es conservar el aprendizaje técnico de la reconstrucción y convertir el proyecto en una base más adecuada para publicación pública en GitHub y GitHub Pages.

## Objetivos

- demostrar desarrollo front-end sin frameworks;
- practicar HTML semántico;
- construir layouts responsivos;
- aplicar fundamentos de accesibilidad;
- organizar contenido institucional ficticio;
- practicar navegación entre múltiples páginas;
- mantener una arquitectura simple y reproducible;
- documentar la evolución del proyecto.

## 🛠️ Tecnologías

## ✨ Funcionalidades

- navegación entre páginas;

## ▶️ Ejecución local

Clona el repositorio:

```bash
git clone https://github.com/sayjinblackbelt/digital-learning-hub.git
cd digital-learning-hub
```

Abre `index.html` en un navegador o utiliza **Live Server** en VS Code.

## 🌐 Publicación

El proyecto puede publicarse directamente con **GitHub Pages**, sin necesidad de servidor ni base de datos.

## 🔐 Privacidad y sanitización

Este repositorio está preparado para publicación pública y no contiene datos personales de terceros, nombres de organizaciones reales, contactos reales, credenciales, documentos restringidos, datos de estudiantes, integraciones privadas ni información operativa confidencial.

Las futuras incorporaciones deben seguir el mismo principio: contenido ficticio, genérico o debidamente autorizado.

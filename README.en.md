## About

**Digital Learning Hub** is an independent project rebuilt from an earlier institutional prototype and repositioned as a **self-contained portfolio case**.

The current version uses the **NEXA Studio** visual language for layout, typography, grid, contrast, components, motion, and graphic direction. All content shown is fictional and sanitized.

## 🎨 Visual direction — NEXA Studio

- **Space Grotesk** for headings and identity;
- **DM Sans** for body text and interface;
- dark technical palette with luminous accents;
- 80px grid;
- restrained borders and minimal shadows;
- expressive typography;
- subtle motion;
- modular and responsive components.

## 🧩 Case studies

The **Work** section presents fictional projects within the same visual system: **Learning OS**, **Creator Lab**, and **Signal / AI**, plus exploratory concepts.

The goal is to demonstrate the chain **problem → system → interface → product**, combining design, front-end development, and visual communication.

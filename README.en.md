# 💻 Digital Learning Hub

[🇧🇷 Português](README.md) | 🇺🇸 English | [🇪🇸 Español](README.es.md)

> A fictional educational institutional website prototype created for front-end study, responsive design, accessibility, and content organization.

## About

**Digital Learning Hub** is an independent project rebuilt from an earlier institutional prototype and repositioned as a **self-contained portfolio case**.

The new version removes references to organizations, services, communication channels, audiences, operational figures, and other elements connected to real-world contexts. All content shown by the website is demonstrational.

The goal is to preserve the technical learning from the reconstruction while making the project safer and more appropriate for public publication on GitHub and GitHub Pages.

## Objectives

- demonstrate framework-free front-end development;
- practice semantic HTML;
- build responsive layouts;
- apply accessibility fundamentals;
- organize fictional institutional content;
- practice multi-page navigation;
- keep a simple, reproducible architecture;
- document project evolution.

## ▶️ Run locally

Clone the repository:

```bash
git clone https://github.com/sayjinblackbelt/digital-learning-hub.git
cd digital-learning-hub
```

Open `index.html` in a browser or use **Live Server** in VS Code.

## 🌐 Deployment

The project can be deployed directly with **GitHub Pages**, with no server or database required.

## 🔐 Privacy and sanitization

This repository is prepared for public publication and contains no personal data from third parties, real organization names, real contact details, credentials, restricted documents, learner data, private integrations, or confidential operational information.

Future additions should follow the same principle: fictional, generic, or properly authorized content only.
